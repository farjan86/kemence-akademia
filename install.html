1. E-mail küldés — Resend API-kulcs + Supabase secretek

A rendszer a Resend szolgáltatáson át küldi a leveleket. Ehhez egy API-kulcs kell, amit a Supabase secretjeként tárolunk. (Fogalmi magyarázat: docs/email.md; teszt-lépések: docs/email-kuldes-setup.md.)

1.1 — Resend API-kulcs létrehozása

  1. Menj a resend.com oldalra és jelentkezz be.
  2. Bal menü: API Keys → Create API Key.
  3. Név: pl. Kemence Akademia (élesre lehet Kemence Akademia - eles).
  4. Jogosultság: elég a Sending access (küldés).
  5. Create → a kulcs re_-vel kezdődik → másold ki azonnal (csak egyszer látszik!).
  6. Mentsd a secrets/titkok.txt fájlba (ez gitignore-olt, nem kerül GitHubra).

1.2 — Supabase secretek beállítása

Supabase → a projekt → Edge Functions → Secrets (Manage secrets) → Add new secret. Két secret kell:

Secret neveÉrték
RESEND_API_KEY a Resend re_… kulcs (lásd secrets/titkok.txt)
MAIL_FROM Fejlesztés: Kemence Akadémia <onboarding@resend.dev>
Éles: a saját, igazolt domained címe, pl. Kemence Akadémia <noreply@kemence-akademia.xyz>
✔ Automatikus: a SUPABASE_URL és a SUPABASE_SERVICE_ROLE_KEY a függvényben magától elérhető — ezeket NEM kell hozzáadni.

1.3 — Éles telepítéskor (EZT NE FELEJTSD!)

  • Az ügyfél saját Supabase-projektjében is be kell állítani ugyanezt a két secretet: RESEND_API_KEY, MAIL_FROM.
  • Az éles feladóhoz a domaint igazolni kell a Resendben (DNS: SPF/DKIM a Hostingeren) — lásd a lenti tervezett DNS-szakaszt.
  • A send-email Edge Function-t deploy-olni kell az ügyfél projektjébe is.
  • A válaszcím (Reply-To) a Csapat e-mail cím (admin → Beállítások); élesben pl. akademia@mobilkemence.xyz.
  • Ha később Google-küldésre váltotok: a secretek GMAIL_USER / GMAIL_APP_PASSWORD lesznek, és a függvény kuld() részét kell átírni.

Tervezett szakaszok bővítjük

Ezeket menet közben töltjük fel részletes lépésekkel, ahogy elkészülnek:

  • Supabase projekt létrehozása + db/01-schema.sql futtatása (SQL Editor)

  • web/js/config.js kitöltése (Project URL + anon kulcs)
  • Admin fiók létrehozása a Supabase Auth-ban (nincs önregisztráció)
  • send-email Edge Function deploy
  • Domain igazolása a Resendben + DNS-rekordok (SPF/DKIM) a Hostingeren
  • pg_cron: napi emlékeztető a másnapi jóváhagyott foglalásoknak
  • Keep-alive ping (hogy az ingyenes Supabase ne aludjon el)
  • Hostinger hosting + DNS élesítés (A-rekord a domainhez)
