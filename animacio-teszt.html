3. Hol kapcsolható vissza?

  • Windows: Beállítások → Kisegítő lehetőségek → Vizuális effektusok → Animációs effektusok = Be
  • Windows akkumulátorkímélő: Beállítások → Rendszer → Energiaellátás → Akkumulátorkímélő ki (töltőre téve)
  • Chrome: chrome://settings/performance → Energiatakarékos mód ki
  • Chrome grafikus gyorsítás: chrome://settings/system → „Hardveres gyorsítás használata" = Be
